## Как исправить проблему с Electron

### Вариант 1: Ручная установка (рекомендуется)

```bash
# Удалите node_modules
rm -rf node_modules

# Установите зависимости заново
npm install

# Запустите скрипт установки Electron вручную
cd node_modules/electron
node install.js
cd ../..

# Проверьте установку
npm start
```

### Вариант 2: Использование npx

```bash
npx electron .
```

### Вариант 3: Переустановка Electron

```bash
npm uninstall electron
npm install electron@31.0.0 --save-dev --legacy-peer-deps
```

### Вариант 4: Очистка кэша npm

```bash
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

## Тестовые сценарии

### 1. Тест стартовой производительности
**Цель:** Проверить скорость запуска приложения

1. Запустите `npm start`
2. Засеките время от старта до появления интерфейса
3. **Ожидаемый результат:** < 1 секунды после готовности сервера

### 2. Тест поиска с debounce
**Цель:** Проверить плавность поиска

1. Откройте приложение
2. Начните быстро вводить текст в поле поиска
3. **Ожидаемый результат:** Фильтрация происходит с задержкой 300мс, нет лагов

### 3. Тест skeleton loader
**Цель:** Проверить отображение загрузки

1. Переключитесь между клубами
2. **Ожидаемый результат:** Видите анимированные skeleton loaders вместо пустого экрана

### 4. Тест модального окна
**Цель:** Проверить производительность модальных окон

1. Кликните на любой ПК в списке
2. Переключайтесь между вкладками "Игры" и "Логи"
3. Закройте окно через Escape
4. **Ожидаемый результат:** Мгновенное открытие/закрытие, плавные переходы

### 5. Тест массовых операций
**Цель:** Проверить отклик на массовые действия

1. Выберите несколько игр в меню "Игры"
2. Нажмите "Обновить свободные"
3. **Ожидаемый результат:** Мгновенный отклик UI, уведомление об успехе

### 6. Тест сетевых запросов
**Цель:** Проверить оптимизацию polling

1. Откройте DevTools (F12)
2. Перейдите на вкладку Network
3. Наблюдайте за частотой запросов к `/api/pcs`
4. **Ожидаемый результат:** Запросы идут каждые 5 секунд, а не каждые 2

### 7. Тест истории
**Цель:** Проверить оптимизацию обновления истории

1. Откройте модальное окно "История"
2. Проверьте частоту обновления в Network
3. **Ожидаемый результат:** Обновление каждые 10 секунд

### 8. Стресс-тест рендеринга
**Цель:** Проверить производительность при большом списке ПК

1. Выберите клуб с максимальным количеством ПК
2. Быстро переключайте сортировку
3. Быстро вводите и удаляйте текст в поиске
4. **Ожидаемый результат:** Нет зависаний, плавные переходы

## Решение типичных проблем

### Проблема: Electron не запускается
**Решение:** Переустановите Electron вручную (см. раздел выше)

### Проблема: Сервер не отвечает
**Решение:** Убедитесь что порт 3000 свободен, перезапустите приложение

### Проблема: ПК не появляются в списке
**Решение:** 
1. Проверьте подключение к SmartShell API
2. Убедитесь что агенты запущены на ПК
3. Проверьте учетные данные клубов в `server/index.js`

### Проблема: Долгая загрузка
**Решение:** Проверьте сетевое соединение, SmartShell API может быть медленным
