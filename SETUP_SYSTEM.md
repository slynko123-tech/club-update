# Система первичной настройки v1.0.9

## Что изменилось:

### 🎯 Главное нововведение
**При первом запуске появляется окно настройки**, где нужно ввести:
- Название клуба
- Телефон менеджера SmartShell
- Пароль от SmartShell
- Company ID (ID компании в SmartShell)

### 💾 Сохранение данных
- Данные сохраняются в `app-config.json` (корень проекта)
- **Токены кешируются на 55 минут** - не запрашиваются при каждом запуске
- При следующих запусках окно настройки не появляется

### 🔒 Безопасность
- Пароль хранится локально в зашифрованном виде
- Токен автоматически обновляется только когда истекает
- Данные не передаются никуда кроме SmartShell API

## API эндпоинты:

### GET /api/config
Возвращает текущую конфигурацию (без пароля):
```json
{
  "setupCompleted": true,
  "club": "club_2165",
  "clubName": "Староминская",
  "companyId": "2165"
}
```

### POST /api/config/setup
Сохраняет настройки и проверяет подключение к SmartShell:
```json
{
  "clubName": "Мой клуб",
  "phone": "79001234567",
  "password": "password123",
  "companyId": "2165"
}
```

Ответ при успехе:
```json
{
  "success": true,
  "message": "Настройка завершена успешно!"
}
```

Ответ при ошибке:
```json
{
  "error": "Неверные данные SmartShell. Проверьте телефон, пароль и ID компании."
}
```
