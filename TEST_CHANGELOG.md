# Тестирование Changelog v1.0.9

## Как протестировать окно с изменениями:

### Способ 1: Очистка localStorage (в браузере DevTools)
1. Откройте приложение: `npm start`
2. Откройте DevTools (F12)
3. Перейдите в Console
4. Выполните: `localStorage.removeItem('lastSeenVersion')`
5. Обновите страницу (F5)
6. **Должно появиться окно с изменениями версии 1.0.9**

### Способ 2: Очистка через Application
1. Откройте приложение
2. DevTools (F12) → Application → Local Storage
3. Найдите ключ `lastSeenVersion` и удалите его
4. Обновите страницу (F5)

## Что было исправлено в этой версии:

- Раньше: компьютеры с клиентами показывались как "Свободен"

### 2. Кнопка удаления (src/App.tsx)
- Раньше: кнопка "Удалить" не всегда была видна

- Добавлено: подтверждение с названием игры
- Добавлено: красный прогресс-бар при удалении
