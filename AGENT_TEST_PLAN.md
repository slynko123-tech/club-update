## Тестовые сценарии

### Сценарий 1: Базовая проверка соединения
1. Запустить приложение
2. Выбрать клуб из списка
3. Убедиться что список ПК загружается
4. **Ожидаемый результат:** Видны все ПК клуба с актуальными данными

### Сценарий 2: Проверка данных ПК
1. Кликнуть на любой ПК
2. Проверить отображение:
   - Статус
   - IP адрес
   - Свободное место
   - Список установленных игр
   - Очередь задач (если есть)
3. **Ожидаемый результат:** Все данные корректны и актуальны

### Сценарий 3: Установка игры
1. Открыть модалку ПК
2. Найти игру которая не установлена
3. Нажать "Установить"
4. Проверить что:
   - Появился индикатор "Отправка..."
   - Задача добавилась в очередь
   - Статус обновляется в реальном времени
5. **Ожидаемый результат:** Игра начала устанавливаться

### Сценарий 4: Проверка обновлений
1. Найти установленную игру
2. Нажать "Проверить"
3. Дождаться результата проверки
4. **Ожидаемый результат:** Статус обновился (✅ Актуален или 🔄 Есть обновление)

### Сценарий 5: Массовое обновление
1. Выбрать 2-3 игры в левой панели
2. Нажать "Обновить свободные"
3. Проверить что:
   - Задачи добавились на все свободные ПК
   - Появилось уведомление с количеством ПК
4. **Ожидаемый результат:** Команды отправлены на N свободных ПК

### Сценарий 6: Очистка мастерской
1. Открыть модалку ПК
2. Нажать "Очистить Мастерскую"
3. Подтвердить действие
4. **Ожидаемый результат:** Команда отправлена, задача в очереди

### Сценарий 7: Обновление агента
1. Открыть модалку ПК
2. Нажать "Обновить агента"
3. Подтвердить действие
4. **Ожидаемый результат:** Команда отправлена, агент обновляется

### Сценарий 8: Отмена задач
1. Найти ПК с активными задачами
2. Нажать "Отменить всё"
3. Подтвердить действие
4. **Ожидаемый результат:** Все задачи отменены

### Сценарий 9: История операций
1. Нажать "История" в шапке
2. Проверить что отображаются:
   - Дата и время операции
   - Компьютер
   - Действие
   - Игра (если применимо)
3. **Ожидаемый результат:** История актуальна и обновляется

### Сценарий 10: Логи ПК
1. Открыть модалку ПК
2. Переключиться на вкладку "Логи"
3. Проверить отображение логов
4. **Ожидаемый результат:** Логи показываются, автоскролл работает

## Автоматическая проверка

Запустите скрипт:
```bash
node test-agent.js
```

Скрипт проверит:
- Доступность SmartShell API
- Формат ответов
- Обработку ошибок
- Время отклика

## Проверка производительности агента

### Метрики для проверки:
- Время ответа API: < 2 секунды
- Интервал polling: 5 секунд
- Обновление данных ПК: в реальном времени
- Задержка отправки команд: < 1 секунды

## Известные особенности

### SmartShell API:
- Требует авторизацию по номеру телефона
- Возвращает данные в формате JSON
- Поддерживает команды через POST запросы
- Имеет ограничение на частоту запросов

### Агент на ПК:
- Автоматически подключается к серверу по UDP
- Отправляет статус каждые несколько секунд
- Обрабатывает команды из очереди последовательно
- Логирует все действия
